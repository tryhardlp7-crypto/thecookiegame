# 🤖 Mon IA de Trading & Placement

Ce projet est un algorithme complet et 100% gratuit écrit en Python. Il utilise le **Machine Learning** pour analyser les marchés financiers, déterminer où placer son argent et exécuter des règles strictes de sortie (*Take Profit* et *Stop Loss*) pour sécuriser les gains.

## ✨ Fonctionnalités
- **Données Gratuites :** Extraction des prix historiques via l'API Yahoo Finance (`yfinance`).
- **Signaux Mathématiques :** Analyse via RSI et Moyennes Mobiles.
- **Intelligence Artificielle :** Modèle `Random Forest` qui apprend des données passées.
- **Gestion du Risque :** Retrait automatique à +5% de profit ou -2% de perte.

## 🚀 Comment le lancer gratuitement (Sans rien installer)

1. Ouvrez un compte gratuit sur [Google Colab](https://google.com).
2. Créez un **Nouveau Notebook**.
3. Installez les outils requis en collant cette ligne dans une cellule et en l'exécutant :
   ```bash
   !pip install -r https://githubusercontent.com
   ```
4. Copiez le code du fichier `bot.py` dans une nouvelle cellule et cliquez sur **Play** ▶️.
