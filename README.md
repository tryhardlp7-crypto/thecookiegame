# 🤖 Application Web Interactive de Trading par IA

Ce dépôt contient une application financière complète et gratuite qui utilise le Machine Learning pour simuler des placements boursiers ou cryptos.

## 🚀 Comment l'activer en ligne gratuitement en 1 minute :
1. Créez un compte gratuit sur [Streamlit Share](https://streamlit.io).
2. Connectez votre compte GitHub.
3. Cliquez sur **"New app"**, sélectionnez ce dépôt GitHub, puis le fichier `app.py`.
4. Cliquez sur **"Deploy"** ! Votre application est en ligne avec un lien public accessible à tous.
